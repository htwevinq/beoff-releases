Тема «Достань кореша» использует шрифт [FontStuck Extended](https://fontstruct.com/fontstructors/show/634388/radrussianrus)
автора RadRussianRus (сделан на FontStruct) без изменений. Лицензия — [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

Смайлы на сайте — набор [OpenMoji](https://openmoji.org), открытый проект эмодзи и иконок (HfG Schwäbisch Gmünd), без изменений.
